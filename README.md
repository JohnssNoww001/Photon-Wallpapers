# Photon Wallpapers

**A free wallpaper app for Windows.** Browse thousands of pictures and live (video) wallpapers, set them with one click, and let Photon change them for you automatically.

[**Download the latest version**](https://github.com/JohnssNoww001/Photon-Wallpapers/releases/latest)

## Features

**Find wallpapers**
- **Web Search:** search Wallhaven from inside the app, with category chips and filters
- **Featured:** a hand-picked collection, updated online without a new app version
- **My PC Wallpapers:** use your own pictures and videos, including drag and drop
- **Favorites:** keep the ones you love, with backup and restore

**Live wallpapers**
- Play video wallpapers on your desktop
- Browse free live clips, or use your own videos
- Sound control, fill or fit mode, and effects: blur, greyscale and dim
- Pauses automatically when a full-screen app is running or when you are on battery, to save power

**Pictures and lock screen**
- Set any picture as your desktop wallpaper
- Set it as your Windows lock screen too, or let the lock screen follow your wallpaper automatically

**Automatic and fast**
- **Auto-change** wallpapers on a timer, from your chosen pool
- **Random wallpaper at startup**
- **Global hotkeys** that work in any app:

| Hotkey | Action |
|---|---|
| `Ctrl + Alt + N` | Next wallpaper |
| `Ctrl + Alt + F` | Add the current wallpaper to Favorites |

**Made to stay out of your way**
- Lives in the system tray, can start with Windows and open minimized
- Storage page to see and clear the cache
- Save any wallpaper to a folder on your PC
- Built-in updater: the app tells you when a new version is ready
- Light, dark and colour themes

## Install

1. Open the [latest release](https://github.com/JohnssNoww001/Photon-Wallpapers/releases/latest).
2. Download the installer (`.exe`) and run it.
3. Open **Photon Wallpapers** and pick something you like.

After that, updates install from inside the app (**Check for updates**).

## Built with

[Tauri v2](https://tauri.app) (Rust) and React + Vite. Small, fast, and light on memory.
